# java-lotto-precourse
# 로또 미션 기능 명세서

## 입력 기능

구입 금액 입력 받기
- 1,000원 단위로 입력 받기
- 1,000원으로 나누어떨어지지 않으면 예외 처리

당첨 번호 입력 받기
- 쉼표로 구분된 6개의 숫자 입력
- 1~45 범위의 숫자인지 검증
- 중복된 숫자가 없는지 검증
- 6개의 숫자가 맞는지 검증

보너스 번호 입력 받기
- 1개의 숫자 입력
- 1~45 범위의 숫자인지 검증
- 당첨 번호와 중복되지 않는지 검증

## 로또 발행 기능

구입 금액을 1,000원으로 나누어 로또 개수 계산
1~45 범위에서 중복되지 않는 6개의 숫자 추출
생성된 로또 번호를 오름차순으로 정렬
발행된 로또 개수와 번호 출력

## 당첨 확인 기능

각 로또와 당첨 번호 비교하여 일치 개수 계산
보너스 번호 일치 여부 확인
당첨 등수 판정
- 6개 일치: 1등 (2,000,000,000원)
- 5개 일치 + 보너스: 2등 (30,000,000원)
- 5개 일치: 3등 (1,500,000원)
- 4개 일치: 4등 (50,000원)
- 3개 일치: 5등 (5,000원)

## 결과 출력 기능

당첨 통계 출력
- 각 등수별 당첨 개수 출력
- 3개 일치부터 6개 일치까지 순서대로 출력

수익률 계산 및 출력
- 총 당첨 금액 계산
- 수익률 = (총 당첨 금액 / 구입 금액) * 100
- 소수점 둘째 자리에서 반올림

## 예외 처리 기능

구입 금액이 1,000원 단위가 아닐 때 예외 발생
로또 번호가 1~45 범위를 벗어날 때 예외 발생
로또 번호에 중복이 있을 때 예외 발생
로또 번호가 6개가 아닐 때 예외 발생
보너스 번호가 당첨 번호와 중복될 때 예외 발생
보너스 번호가 1~45 범위를 벗어날 때 예외 발생
예외 발생 시 "[ERROR]"로 시작하는 메시지 출력
예외 발생 부분부터 재입력 받기
